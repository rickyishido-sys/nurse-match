### 本文

**体験から始まる、新しいつながり**

HANAKAI Connectionは、「知らない人同士がリアルで出会う、週替わりのイベントコミュニティ」です。スワイプ型マッチングではなく、実際の体験（イベント）を通じて、参加者同士のつながり（Connection）を育てることを目的としています。

**こんな方におすすめ**

- 新しい趣味や体験を通じて、自然な形で人と出会いたい
- オンラインだけでなく、リアルな場で交流したい
- 安全に配慮されたコミュニティに参加したい
- 散歩・カフェ・花など、落ち着いた雰囲気のイベントに興味がある

**主な機能（Ver1.0）**

- **イベント閲覧・参加申込** — カテゴリやエリアでイベントを探し、参加を申し込めます
- **プロフィール作成・編集** — ニックネーム、年代、居住エリア、興味・価値観、写真などを登録
- **参加審査** — 主催者または運営が参加申請を確認します
- **参加のキャンセル** — 申請済みの参加をキャンセルできます
- **イベントの作成・編集・中止** — ユーザー自身がイベントを主催・管理できます
- **参加者一覧** — 参加確定したイベントの参加者プロフィールを確認できます
- **通報・ブロック** — 迷惑行為や不安を感じた相手を通報、またはブロック可能
- **アカウント削除** — アプリ内から退会手続きが可能（`/account/delete`）

**Ver1.0で提供していない機能**

- メッセージ・DM、投稿・コメント、ライブ配信、投げ花・応援・決済、イベント後のアプリ内交流

**安全への取り組み**

- 18歳以上の方を対象としています
- 参加承認（主催者・運営による審査）
- 本人確認書類の提出（任意）
- 通報機能と運営による対応体制
- ブロック機能により、特定のメンバーを非表示にできます
- コミュニティガイドライン・利用規約・プライバシーポリシーを整備

**料金について**

- アプリのダウンロード・基本機能の利用は無料です
- **アプリ内課金はありません**
- イベント参加費がある場合は、**当日会場で現地払い**です（アプリ内決済は行いません）

**位置情報について**

- 本アプリは**常時・バックグラウンドでの位置情報追跡を行いません**
- プロフィールに居住エリア（例：東京都）を登録する場合がありますが、GPSによる継続的な位置取得は行いません

**ご利用にあたって**

- インターネット接続が必要です
- 一部機能はログインが必要です
- イベントの開催状況・参加条件は各イベントページをご確認ください

**お問い合わせ**

アプリ内のお問い合わせフォーム、または Web サイト（https://hanakai.kranz.design/contact）よりご連絡ください。
