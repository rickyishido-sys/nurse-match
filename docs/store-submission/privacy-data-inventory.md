## 2. データの利用目的

| 目的 | 該当データ |
|------|------------|
| アカウント作成・認証 | メールアドレス |
| プロフィール表示・マッチング設計 | プロフィール情報 |
| イベント運営・参加管理 | 申込情報、プロフィール |
| 安全管理（通報・ブロック対応） | 通報内容、ブロック関係 |
| お問い合わせ対応 | お問い合わせ内容、メール |
| サービス改善・障害対応 | ログ情報 |
| AI 機能（自己紹介下書き等） | プロフィールテキスト（利用時のみ） |

> ⚠️ **要確認（法務）:** OpenAI 等の AI サービス利用時のデータ送信範囲・オプトアウト方針をプライバシーポリシーと一致させてください。

## 3. 第三者へのデータ共有

| サービス | 提供者 | 共有データ | 目的 |
|----------|--------|------------|------|
| Supabase | Supabase Inc. | 認証情報、DB データ、Storage ファイル | 認証・DB・ファイル保存 |
| Vercel | Vercel Inc. | リクエストログ、配信データ | ホスティング・CDN |
| OpenAI | OpenAI | プロフィールテキスト（AI 利用時） | AI 下書き生成 |

> ⚠️ **要確認（法務）:** 各サービスの DPA（データ処理契約）、データ所在地（リージョン）、サブプロセッサー一覧を確認してください。

## 4. データの保持・削除

| 操作 | 実装 |
|------|------|
| アカウント削除 | `/account/delete` — 論理削除 + `hanakai_account_deletion_requests` |
| 削除後の保持 | 安全確認・通報対応・法令順守のため一定期間保持する場合あり |
| ユーザーによるデータエクスポート | Ver1.0 では**未実装** |

> ⚠️ **要確認（法務・Apple / Google）:**
> - Apple はアカウント削除の容易なアクセスを要求
> - GDPR / 個人情報保護法に基づく削除・開示請求への対応手順を整備
> - 削除後の保持期間を具体的な日数で定義

## 7. Google Play — Data safety 申告ガイド

| データ型 | 収集 | 共有 | 処理目的 | オプション |

| メールアドレス | はい | いいえ | アカウント管理 | 必須 |

追加申告:

- データは暗号化して転送: **はい**（HTTPS）

- データ収集は必須か: 一部任意（写真、SNS URL 等）

> ⚠️ **要確認（Google）:** Data safety フォームは年次更新が必要です。機能追加時は随時更新してください。
