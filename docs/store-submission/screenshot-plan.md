## 1. 必要枚数・サイズ

### App Store（iOS）

| デバイス | 解像度 | 必須 | 推奨枚数 |
|----------|--------|------|----------|
| **iPhone 6.7"（iPhone 15 Pro Max 等）** | 1290 × 2796 | **はい（基本）** | **6** |
| iPhone 6.9"（iPhone 16 Pro Max） | 1320 × 2868 | 任意（あれば追加） | 6 |
| iPad | — | **不要** | — |

> ✅ 本アプリは **iPhone 専用**（TARGETED_DEVICE_FAMILY = 1）のため、iPad スクリーンショットは不要です。
> ⚠️ **要確認（Apple）:** 必須サイズは App Store Connect の最新要件に従ってください。6.7" を基本セットとします。

### Google Play（Android）

| 種別 | 解像度 | 必須 | 推奨枚数 |
|------|--------|------|----------|
| スマートフォン | 1080 × 1920 以上（16:9） | はい | 4〜8 |
| 7インチタブレット | 1200 × 1920 | 任意 | 4〜8 |
| 10インチタブレット | 1600 × 2560 | 任意 | 4〜8 |
| フィーチャーグラフィック | 1024 × 500 | はい | 1 |

## 2. 確定スクリーン構成（6枚 / 6.7インチ iPhone 基本）

Ver1.0 で実際に提供している機能のみを訴求します（未提供機能・イベント後交流は掲載しない）。

| # | 画面 | パス | 短いキャッチコピー（App Store 用） |
|---|------|------|--------------------------------------|
| 1 | イベント一覧 | `/events` | 週替わりのリアルイベントを探す |
| 2 | イベント詳細 | `/events/[id]` | 気になるイベントに参加申込 |
| 3 | プロフィール | `/my-profile` | あなたらしさが伝わるプロフィール |
| 4 | 本人確認 | `/my-profile`（本人確認セクション） | 本人確認で、安心してつながれる |
| 5 | イベント作成 | `/events/create` | 誰でも、自分のイベントを主催できる |
| 6 | 安心・安全機能 | `/`（安全セクション）or プロフィール（通報/ブロック） | 通報・ブロック・運営対応で安心 |

> キャッチコピーは1画面あたり15〜20文字程度に収め、画像内オーバーレイに使用します（任意）。誤解を招く未実装機能の暗示は禁止（Apple ガイドライン）。

## 3. 撮影条件

| 項目 | 設定 |
|------|------|
| 言語 | 日本語 UI |
| テーマ | ライトモード（ブランドカラー `#2F6F62` / `#F8F7F3`） |
| ログイン状態 | 全6枚を審査用アカウントでログインした状態で撮影 |
| 個人情報 | 実在ユーザーの情報を含めない（ダミーデータ使用） |
| 日付 | 審査期間中に有効なイベント日付を表示 |
| ステータスバー | フルバッテリー・フル信号の推奨（審査・訴求用） |

## 4. 撮影方法

### 方法 A: Playwright E2E（推奨 — 既存スクリプト活用）

リポジトリ内の既存スクリーンショットを参考:

```
scripts/e2e-screenshots/
├── brand-redesign-prod/     # ランディング・登録・ログイン等
├── landing-ux-prod/         # ランディング ヒーロー・ステップ
├── events-copy-prod/        # イベント一覧
├── event-detail-prod/       # イベント詳細
└── my-profile-ux-*.png      # プロフィール
```

本番 URL での再撮影:

```bash
# 例: 本番 URL を指定してスクリーンショット取得
BASE_URL=https://hanakai.kranz.design npx playwright test [script]
```

> ⚠️ **要人間対応:** Playwright スクリプトの調整・実行は担当者が行ってください。

### 方法 B: 実機シミュレータ / エミュレータ

Capacitor ビルド後:

1. iOS Simulator / Android Emulator でアプリ起動
2. 審査用アカウントでログイン
3. 各画面をキャプチャ

### 方法 C: ブラウザ DevTools（暫定）

1. Chrome DevTools → デバイスモード
2. iPhone 15 Pro Max（430 × 932）または Pixel 7（412 × 915）
3. 本番 URL を開いてキャプチャ

## 7. 禁止・注意事項

| 項目 | 理由 |
|------|------|
| 未実装機能の表示 | 審査リジェクトリスク（DM 送信 UI 等） |
| 実在ユーザーの顔・名前 | プライバシー |
| 他社商標の無断使用 | 著作権 |
| 過度な Before/After 表現 | ストアガイドライン違反 |
| 出会い系・恋愛系の過剰訴求 | カテゴリ誤判定リスク |

## 8. 納品チェックリスト

### App Store

- [ ] iPhone 6.7"（1290×2796）スクリーンショット 6枚
- [ ] 全画像が PNG または JPEG
- [ ] 個人情報のマスキング確認
- [ ] キャプションの誤字チェック
- [ ] iPad 版は不要（iPhone 専用アプリ）

### Google Play

- [ ] スマートフォンスクリーンショット 4枚以上
- [ ] フィーチャーグラフィック 1024×500
- [ ] 高解像度アイコン 512×512
- [ ] プロモーション動画（任意）

### 共通

- [ ] 審査用アカウントでログイン状態の画面を使用
- [ ] イベント日付が審査期間内
- [ ] ブランドカラー・フォントの一貫性
- [ ] ストア説明文（`app-store-description-ja.md` / `google-play-description-ja.md`）との整合
