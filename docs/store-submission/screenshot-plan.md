## 1. 必要枚数・サイズ

出典: [Apple Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/screenshot-specifications)（2026-08-11 確認）

### App Store（iOS）

現行 ASC の iPhone 主枠は **6.9" Display**（旧「6.7インチ」単独枠は統合済み）。受理サイズ:

| デバイスクラス | 受理解像度（portrait） | 必須 | 推奨枚数 |
|----------------|------------------------|------|----------|
| iPhone 6.9" Display | **1320 × 2868** / 1290 × 2796 / 1260 × 2736 | はい | 6（最大10） |
| iPhone 6.5" | 1284 × 2778 / 1242 × 2688 | 6.9" 未提出時のみ | — |
| iPad 13" Display | 2064 × 2752 / 2048 × 2732 | **iPad 対応 Build のとき必須** | 6 |

固定方針:

- **主成果物: 1320 × 2868 PNG（非透過・アルファなし）**
- 互換: 1290 × 2796 も 6.9" クラスで受理される（旧 6.7" 相当）
- Capacitor 雛形の `TARGETED_DEVICE_FAMILY` デフォルトは `"1,2"`。アップロード済み Build が iPhone 専用かは ASC で要確認（未確認のまま iPad 枠を省略しない）

### Google Play（Android）

| 種別 | 解像度 | 必須 | 推奨枚数 |
|------|--------|------|----------|
| スマートフォン | 1080 × 1920 以上（16:9） | はい | 4〜8 |
| 7インチタブレット | 1200 × 1920 | 任意 | 4〜8 |
| 10インチタブレット | 1600 × 2560 | 任意 | 4〜8 |
| フィーチャーグラフィック | 1024 × 500 | はい | 1 |

## 2. 推奨スクリーン構成（App Store 必須6枚）

詳細な選定理由・個人情報チェック・課金回避は `app-store-screenshot-prep-report.md` を参照。

審査通過と訴求のバランスを考慮した推奨順序（Production + 審査用アカウント + 審査用公開イベント）:

| # | 画面 | パス | キャプション案（日本語） |
|---|------|------|--------------------------|
| 1 | ホーム | `/home` | 会いたい人と、リアルでつながる。 |
| 2 | イベント一覧 | `/events` | 気になるイベントを見つける |
| 3 | イベント詳細 | `/events/a27f5be8-a875-461c-9fd1-adfb936410ff` | 体験の詳細を確かめて、次の一歩へ |
| 4 | 参加申請 | 上記詳細 `#event-apply` | 想いを添えて参加申請 |
| 5 | プロフィール | `/my-profile` | プロフィールから、人柄を知る |
| 6 | イベント作成 | `/events/create` | 誰でもイベントを主催できる |

> **禁止:** 申請送信・Square カード保存・実課金、Smoke データ、レガシーマッチング UI、実ユーザー情報。  
> グループフィード / DM は Ver1.0 スコープ外のため構成に含めない。

## 4. 撮影方法

### 方法 A: Playwright E2E（推奨 — 既存スクリプト活用）

リポジトリ内の既存スクリーンショットを参考:

```
scripts/e2e-screenshots/
├── brand-redesign-prod/     # ランディング・登録・ログイン等
├── landing-ux-prod/         # ランディング ヒーロー・ステップ
├── events-copy-prod/        # イベント一覧
├── event-detail-prod/       # イベント詳細
└── my-profile-ux-*.png      # プロフィール
```

本番 URL での再撮影:

```bash
# 例: 本番 URL を指定してスクリーンショット取得
BASE_URL=https://hanakai.kranz.design npx playwright test [script]
```

> ⚠️ **要人間対応:** Playwright スクリプトの調整・実行は担当者が行ってください。

### 方法 B: 実機シミュレータ / エミュレータ

Capacitor ビルド後:

1. iOS Simulator / Android Emulator でアプリ起動
2. 審査用アカウントでログイン
3. 各画面をキャプチャ

### 方法 C: ブラウザ DevTools（暫定）

1. Chrome DevTools → デバイスモード
2. iPhone 15 Pro Max（430 × 932）または Pixel 7（412 × 915）
3. 本番 URL を開いてキャプチャ

## 5. ストア用フレーム・キャプション

### App Store

- Xcode の Screenshot フレーム、または Figma テンプレートでデバイス枠を追加
- キャプションは画像内にテキストオーバーレイ（任意）
- Apple のガイドライン: 誤解を招く表示（未実装機能の暗示等）を避ける

### Google Play

- フィーチャーグラフィック（1024×500）を1枚作成
- スマートフォンスクリーンショットにキャプションオーバーレイ可能
- プロモーション動画（任意）: 30秒以内

## 7. 禁止・注意事項

| 項目 | 理由 |
|------|------|
| 未実装機能の表示 | 審査リジェクトリスク（DM 送信 UI 等） |
| 実在ユーザーの顔・名前 | プライバシー |
| 他社商標の無断使用 | 著作権 |
| 過度な Before/After 表現 | ストアガイドライン違反 |
| 出会い系・恋愛系の過剰訴求 | カテゴリ誤判定リスク |

## 8. 納品チェックリスト

### App Store

- [ ] iPhone 6.9" スクリーンショット 5枚以上
- [ ] 全画像が PNG または JPEG
- [ ] 個人情報のマスキング確認
- [ ] キャプションの誤字チェック
- [ ] ダークモード版（任意）

### Google Play

- [ ] スマートフォンスクリーンショット 4枚以上
- [ ] フィーチャーグラフィック 1024×500
- [ ] 高解像度アイコン 512×512
- [ ] プロモーション動画（任意）

### 共通

- [ ] 審査用アカウントでログイン状態の画面を使用
- [ ] イベント日付が審査期間内
- [ ] ブランドカラー・フォントの一貫性
- [ ] ストア説明文（`app-store-description-ja.md` / `google-play-description-ja.md`）との整合
